# 🛍️ Products Explorer

A responsive product catalog web application built with JavaScript, HTML, and CSS. It fetches real product data from the DummyJSON API and allows users to explore, search, filter, sort, and view product details.

## ✨ Features

- Fetch products from a REST API.
- Dynamic product cards rendering.
- Search products by title.
- Filter products by category.
- Sort products by price and title.
- Pagination with Next and Previous buttons.
- Product details modal with image and information.
- Loading, error, and empty states.
- Responsive layout for different screen sizes.

## 🛠️ Technologies

- HTML5
- CSS3 (Grid and Responsive Design)
- JavaScript (ES6+)
- Fetch API
- Async/Await
- JavaScript Modules
- DOM Manipulation

## 🌐 API

Product data provided by [DummyJSON](https://dummyjson.com/products).

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open `index.html`.
5. Click **Go Live**.

## 📁 Project Structure

- `index.html` – Application structure.
- `style.css` – Styling and responsive layout.
- `main.js` – Application logic and event handling.
- `api.js` – API requests.
- `ui.js` – Product rendering and modal interface.
